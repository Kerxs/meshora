# 路线图

## 当前状态：M1 开发中

**还没有能运行的程序，也没有可下载的二进制。** M1 的几项已经有了能通过测试的代码，但还没有组装成能用的东西。

这一页不打算粉饰进度。下面每一项后面的状态标记是真实的：

| 标记 | 含义 |
| --- | --- |
| 设计中 | 在讨论方案，还没动代码 |
| 开发中 | 有代码在写，但还不能用 |
| 可用 | 能跑，有人在用 |

截至今天，**M0 地基基本完成，M1 刚开始**：数据面在测试里能完成真实的 WireGuard 握手和加解密，
Linux 虚拟网卡实测能收发报文 —— 但它们还没被接成一个能运行的程序，没有任何一项达到「可用」。

## M1 打通主干

目标：**两台 Windows 机器，一条加密隧道，能互相 ping 通。**

| 项目 | 状态 |
| --- | --- |
| 节点身份与注册（公钥即身份，Noise IK 认证） | 设计中 |
| boringtun 集成 | 开发中 |
| wintun 虚拟网卡 | 开发中 |
| 控制面最小实现（发现 + 密钥分发） | 设计中 |
| 端点探测（类 STUN） | 设计中 |
| UDP 打洞协调 | 设计中 |
| Relay 回退 | 设计中 |

- **boringtun 集成**：两个数据面在测试里完成真实的握手和加解密，本机 UDP 上 ping 得通
- **wintun 虚拟网卡**：只做过编译检查，还没在 Windows 上跑过

这是整个项目最关键的里程碑。**M1 跑通之前，其余全是纸面工作。**

## 平台

| 平台 | 状态 |
| --- | --- |
| Windows（wintun） | 开发中 |
| Linux（含服务器 / NAS） | 开发中 |
| macOS | 设计中 |
| Android / iOS | 设计中 |
| OpenWrt | 设计中 |

Windows 优先，因为开发机是它，而且最难的分应用分流在 Windows 上 —— 先啃硬的能更早暴露设计问题。

不过眼下实测跑得最多的反而是 Linux：开发用的云端环境是 Linux，虚拟网卡的测试在那里能真跑。
Windows 这边暂时只有 CI 里的编译和单元测试。
