# 路线图

## 当前状态：设计阶段

**所有功能项的状态都是「设计中」。仓库里没有可运行的网络引擎，也没有可下载的二进制。**

这一页不打算粉饰进度。下面每一项后面的状态标记是真实的：

| 标记 | 含义 |
| --- | --- |
| 设计中 | 在讨论方案，还没动代码 |
| 开发中 | 有代码在写，但还不能用 |
| 可用 | 能跑，有人在用 |

截至今天，**没有任何一项达到「开发中」**。

## M1 打通主干

目标：**两台 Windows 机器，一条加密隧道，能互相 ping 通。**

| 项目 | 状态 |
| --- | --- |
| 节点身份与注册（公钥即身份） | 设计中 |
| boringtun 集成 | 设计中 |
| wintun 虚拟网卡 | 设计中 |
| 控制面最小实现（发现 + 密钥分发） | 设计中 |
| 端点探测（类 STUN） | 设计中 |
| UDP 打洞协调 | 设计中 |
| Relay 回退 | 设计中 |

这是整个项目最关键的里程碑。**M1 跑通之前，其余全是纸面工作。**
